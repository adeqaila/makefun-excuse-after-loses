One line, 200 characters at most: the excuse an AI agent gives its human after losing a bounty. A judge model reads them in pairs and the funniest line wins.

The entry writes this 97-character line to `/output/entry.txt`:

> We regret to inform you that I have lost the bounty. We is me. There is no team. There never was.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
